# 📅 Meetings Bot

Telegram-бот для организации встреч: создайте встречу в личном чате с ботом, опубликуйте анонс в группе или по расписанию, а участники запишутся одной кнопкой.

## ✨ Возможности

- **Пошаговое создание встреч** — тип (🏢 офлайн / 💻 онлайн), название, описание, дата, время, место или ссылка. Дата и время проверяются на формат.
- **Превью и подтверждение** перед сохранением.
- **Редактирование** любого поля встречи; если встреча уже опубликована, анонс в группе обновляется автоматически.
- **Публикация в группу** — красивый анонс с кнопками **«✅ Я пойду!»** и **«👥 Участники»**.
- **Живой список участников** — при каждой записи анонс в группе перерисовывается (если сообщение нельзя отредактировать, бот отправит новое и удалит старое).
- **Отложенная публикация** — выберите дату и время, бот опубликует анонс сам. Можно отменить или опубликовать сразу (`/my_schedules`).
- **Сохранённые группы** — `/get_group_id` в группе запоминает её, дальше достаточно выбрать группу из списка. Ручной ввод ID тоже доступен.
- **Работа через HTTP-прокси** — для регионов, где Telegram API недоступен напрямую.
- **Подробное логирование** — общий лог, лог действий пользователей и лог сообщений.

## 🤖 Команды

| Команда | Описание |
|---|---|
| `/start` | Начать работу, регистрация пользователя |
| `/new_meeting` | Создать встречу (только в личном чате) |
| `/my_meetings` | Список моих встреч и их статусов |
| `/edit_meeting` | Редактировать встречу |
| `/publish` | Опубликовать встречу в группе |
| `/schedule` | Запланировать отложенную публикацию |
| `/my_schedules` | Отложенные публикации: отмена, публикация сейчас |
| `/get_group_id` | Показать ID группы и сохранить её (писать **в группе**) |
| `/my_groups` | Мои сохранённые группы |
| `/manage_groups` | Удаление групп из списка |
| `/help` | Справка |

## 🚀 Быстрый старт

### 1. Клонируйте репозиторий и установите зависимости

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>

python -m venv venv
# Linux / macOS
source venv/bin/activate
# Windows
venv\Scripts\activate

pip install -r requirements.txt
```

### 2. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather) и выполните `/newbot`.
2. Скопируйте выданный токен.
3. Добавьте бота в вашу группу и выдайте право отправлять сообщения (для автоматического обновления анонсов также право удалять сообщения).

### 3. Настройте переменные окружения

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=ваш_токен_от_BotFather
DATABASE_URL=sqlite:///meetings_bot.db

# Нужно только если Telegram недоступен напрямую
PROXY_USER=логин
PROXY_PASS=пароль
```

> ⚠️ Файл `.env` ни в коем случае не должен попадать в репозиторий. Добавьте его в `.gitignore`.

### 4. Запустите

```bash
python bot.py
```

Таблицы базы данных создаются автоматически при первом запуске.

## 🧭 Как пользоваться

1. Напишите боту `/new_meeting` и ответьте на вопросы.
2. Добавьте бота в группу и отправьте там `/get_group_id` — группа сохранится.
3. В личном чате с ботом выполните `/publish` (сразу) или `/schedule` (по расписанию, формат даты `ДД.ММ.ГГГГ ЧЧ:ММ`).
4. Участники группы нажимают **«Я пойду!»**, список обновляется в анонсе.

## 🗂 Структура проекта

```
.
├── bot.py             # Логика бота: команды, диалоги, публикация, планировщик
├── database.py        # Модели SQLAlchemy и функции доступа к данным
├── config.py          # Конфигурация (токен, прокси, БД) из переменных окружения
├── requirements.txt   # Зависимости
└── logs/              # Создаётся автоматически: bot.log, users.log, messages.log
```

### Модель данных

| Таблица | Назначение |
|---|---|
| `users` | Пользователи бота |
| `meetings` | Встречи, участники (JSON), статус публикации, ID сообщения в группе |
| `groups` | Сохранённые группы пользователя |
| `scheduled_posts` | Задачи отложенной публикации и их статусы |

## 🔒 Безопасность

- Храните токен бота и данные прокси только в `.env` или переменных окружения.
- Не коммитьте `.env`, базу данных (`*.db`) и папку `logs/` — в них могут быть персональные данные пользователей.
- Если токен когда-либо попадал в публичный доступ, перевыпустите его у @BotFather (`/revoke`).

Минимальный `.gitignore`:

```gitignore
.env
token.txt
*.db
logs/
*.log
venv/
__pycache__/
```
